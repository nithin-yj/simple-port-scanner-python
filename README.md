# Simple Port Scanner using Python

## Overview
This project is a simple Port Scanner developed using Python.  
The scanner checks open ports on a target system using socket programming concepts.

This project was developed as part of a Cybersecurity (CEH-based) internship project.

---

## Features
- Scan open ports on a target IP or website
- User-defined port range
- Displays open ports
- Error handling for invalid targets
- Simple command-line interface

---

## Technologies Used
- Python
- Socket Programming
- TCP/IP Networking
- Command Line Interface (CLI)

---

## Requirements
- Python 3.x

No external libraries are required.

---

## How to Run

### Step 1: Clone Repository
```bash
git clone https://github.com/nithin-yj/simple-port-scanner-python.git
```

### Step 2: Navigate to Project Folder
```bash
cd simple-port-scanner-python
```

### Step 3: Run the Program
```bash
python port_scanner.py
```
